# Turaq

**Turaq** — сервис недвижимости в Казахстане. Слоган: **«Найди своё место»**.

Учебный MVP на моковых данных: без бэкенда, демо-вход и черновики в браузере (`localStorage` / `sessionStorage`).

## Стек

- [Next.js 16](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS (тема Emerald Trust, `darkMode: class`)
- [lucide-react](https://lucide.dev/) — иконки
- Leaflet — карта (зона поиска)

## MVP — что уже есть

| Раздел | Маршрут | Кратко |
|--------|---------|--------|
| Главная | `/` | Hero, категории, подборки |
| Каталог | `/search` | Фильтры по query, карточки |
| Объект | `/property/[id]` | Галерея, описание, избранное, похожие |
| Избранное | `/favorites` | Список из `localStorage` |
| Карта | `/map` | Объявления на карте, зона |
| Вход (демо) | `/login` | Без сервера |
| Подача | `/submit` | Только после входа, черновик в профиль |
| Профиль | `/profile` | Черновики объявлений, выход |

## Локальный запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

Сборка для продакшена:

```bash
npm run build
npm start
```

## Демо-вход

Сервер не используется. На `/login` подойдёт любой корректный **email или телефон** (10 цифр, с 7…) и **пароль от 6 символов**. Сессия хранится в `sessionStorage`.

Примеры сценариев:

1. `/login` → профиль  
2. `/login?next=/submit` → подача объявления  
3. Без входа `/submit` перенаправит на `/login?next=/submit`

## Деплой на Vercel

1. Запушь репозиторий на **GitHub** (без `.env` с секретами — они в `.gitignore`).
2. Зайди на [vercel.com](https://vercel.com) → **Add New… → Project**.
3. **Import** своего репозитория.
4. Framework: **Next.js** (определится автоматически).
5. **Deploy** — для текущего MVP переменные окружения не обязательны.

После деплоя вставь ссылку в портфолио:

```text
LIVE_DEMO_URL=<!-- добавь ссылку после деплоя, например https://turaq.vercel.app -->
```
